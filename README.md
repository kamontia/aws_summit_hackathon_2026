## 主要機能

| # | 機能 | 概要 |
|---|---|---|
| 1 | 言いにくいこと変換 | 不満をそのまま入れると、相手に伝わる文に変換 |
| 2 | 地雷ワード検出 | 「いつも」「なんで」「私ばっかり」を送信前に警告 |
| 3 | 言い方レベル調整 | Lv.1 やさしくお願い 〜 Lv.5 送信前に深呼吸 |
| 4 | 配偶者・家族別チューニング | 相手の傾向（理屈型／頼られる型／防御型）に合わせて文面最適化 |
| 5 | 家庭内 SLA | 洗い物 24h、ゴミ出し 前日 22:00 など、家事を業務システム風に管理 |
| 6 | 謝罪文自動生成 | 火に油を注がない謝罪文を生成 |
| 7 | AI同士の家族会議 | 妻AI・夫AI・調停AI が合意形成し、ユーザー本人は対話に参加しない |

## プラン設計と「人をダメにする度」

| プラン | 価格イメージ | ユーザー負担 | AIに委ねる範囲 | 人をダメにする度 |
|---|---|---|---|---|
| Free | 無料 | 高 (細かい指示が必要) | トーン調整のみ (静的) | 低 |
| Standard | 数百円/月 | 低 (言いたいことだけ) | トーン自動調整 | 中 |
| Pro | 千円前後/月 | ほぼゼロ | バイタル情報から送信タイミングまで | **高** |

**価格が上がるほどユーザーが何も考えなくてよくなる** = 事業性とテーマが一致

## 安全制御への配慮

ブラックユーモアを扱うサービスのため、安全配慮を明示:

| 制御 | 内容 |
|---|---|
| Bedrock Guardrails | 攻撃的・支配的・操作的な表現を抑制（日本語 Optimized） |
| アプリケーションルール | 明確な禁止語の検出 |
| 自動送信の扱い | デモ演出として表現し、実運用では人間承認必須を明記 |
| バイタル情報利用 | 相手の明示的同意・取消可能な連携を前提（Pro 将来拡張） |
| Lv.5 送信 | ポリシーで人間承認必須 |
